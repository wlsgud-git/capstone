clone후 해야 할 일 -------------------------------------

1. vsc의 상단에 File을 눌러 Open Folder를 클릭 후 clone되어있는 폴더로 접속한다
2. ctrl + `을 눌러 Terminal을 연다 그리고 powershell을 총 5개 만든다 ( terminal 닫는창 옆 +버튼 )
3. 1번 powershell에 다음을 입력한다    cd frontend -> npm install -> npm run dev 입력 후 chrome에 들어가서  http://localhost:5173 로 접속 후 제대로 접속이 된다면 



registry 저장방법 )

docker build -t my-frontend:v1 ./frontend
docker login
docker tag my-frontend:v1 아이디/my-frontend:v1
docker push 아이디/my-frontend:v1

kubernetes폴더 및에 모든 폴더에 들어있는 yaml배포 )
kubectl apply -R -f ./kubernetes/

tunnl.gg 터널링 코드 )
ssh -t -R 80:localhost:(port) proxy.tunnl.gg

deployment 재시작 방법)

kubectl rollout restart deployment/frontend-deployment
