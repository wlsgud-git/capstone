docker build -t my-(project-folder):v2 ./(project-folder) 도커 이미지 생성

로컬 호스트로 들어와 지지 않는데 이 때 2가지 방법이 있다 )  
1. 외부 (localhost)에서 pod안으로 들어와서 실행
2. 외부 (localhost)에서 포트포워딩(포트연결)을 통해서 연결

추가:
kubectl exec -it (파드 이름) -- bash -> curl localhost:(포트 번호)
port-forward 명령어 : kubectl port-forward pod/(파드 이름) (로컬 포트번호):(서비스 포트번호)

이미지 풀 정책 ) 
Always : 로컬에서 이미지를 가져오지 않고, 무조건 레지스트리에서 가져옴
IfNotPresent : 로컬에서 이미지를 먼저 가져오고, 없으면 레지스트리에서 가져옴
Never : 로컬에서만 이미지를 가져옴

추가: 
image 태그가 :latest가 명시되지 않은 경우:  Always
image 태그가 :latest가 아닌 경우 : IfNotPresent      

이걸 수동으로 기입하려면 imagePullPolicy : 3개 중 하나를 기입


deployment = (파드를 묶음으로 쉽게 관리할 수 있게 해주는 기능) )
spec.relicas : pod개수

spec.selector : deployment의 세부정보
spec.selector.matchLabels : 해당 Label과 일치하는 Pod를 배포할거라고 명시함

spec.template : 배포할 Pod의 세부 정보

service = (외부로부터 들어오는 트래픽을 받아 파드에 균등하게 분배해주는 로드밸런스 역할))

service의 3가지 종류
1. NodePort: 쿠버네티스 내부에서 해당 서비스에 접속하기 위하나 포트를 열고 외부에서 접속 가능하도록 한다
2. ClusterIP: 쿠버네티스 내부에서만 통신할 수 있는 IP주소를 부여, 외부에서는 요청 불가능
3. LoadBalancer : 외부 로드밸런서를 활용해 외부에서 접속할 수 있도록 연결

추가 : port
nodeport: 외부사용자가 접속하는 port번호
port: 서비스에서 거치는 port번호
targetport: Pod에서거치는 port번호 

nodeport -> port -> targetPort
